Methodology. Controls curated from CIS Google Workspace Foundations Benchmark v1.4.0 (identity, Gmail, Drive, API, devices), Google Admin Security → Security center → Security health, Google’s security checklist for medium/large businesses, administrator-account hardening guidance, and current Gemini / smart-feature Admin paths (Generative AI → Gemini app / Gemini for Workspace). Weights: Critical 5–6, High 4–5, Medium 3–4. Score = earned points ÷ applicable points × 100. Enterprise-only and unused Gemini controls are excluded from the denominator.

Disclaimer. This is a consultant configuration interview, not a live Admin SDK pull and not a certified CIS audit.
