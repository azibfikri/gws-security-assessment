Level 0

Google product baseline

What Google already ships. Confirm it — do not sell it as “we hardened the tenant.”

  • C8 · Less Secure Apps stay blocked + TLS required
  • Core Gmail spam / phishing / malware scanning (always on — not a separate checklist row)
  • Admin console session fixed at 1 hour
  • Rolling admin 2SV (any method) — not security-key-only (that is A2 / Level 1)

Assessment shortcut: Apply Google new-tenant defaults only marks C8.

Level 1

Minimum go-live security

Stop account takeover, domain spoofing, and open Drive/OAuth before users land. Target: first week.

A1 Enforce 2SV for all users
A2 Security keys for Super Admins
A6 Lock account recovery
B1–B3 SPF + DKIM + DMARC (quarantine/reject)
B5 Disable auto-forward; lock IMAP/POP
C1 Restrict Drive external sharing
C2 Restrict unconfigured OAuth
C8 Confirm LSA blocked + TLS

If any of these fail, do not claim Level 1 — even if the score badge looks green-ish.

Level 2

Standard managed

Day-2 hardening every Business tenant can mostly do. Requires Level 1 complete first.

A3–A5 Super-admin hygiene, password 12+, short sessions
A7 Alert Center notifications
B4 · B6 Extra Safety packs + pre-delivery scan
B7 Calendar external = free/busy
C4–C7 Marketplace, publish-to-web, Shared Drive create, Takeout
D1 · D2 · D6 MDM / wipe / Chat+Meet guests

Delivery timeline

  1. Week 0 — Discover. Confirm edition, Gemini scope, MX/DNS ownership, existing SSO. Apply Level 0 check (C8 + eyeball LSA/IMAP after any mail migration).
  2. Week 1 — Level 1. 2SV campaign + admin keys, SPF/DKIM/DMARC, Drive + OAuth lock, forward/IMAP off, recovery lock. Freeze user onboarding until A1 is enforcing or a dated enforcement plan exists.
  3. Day 30 — Level 2. Safety packs, sessions, Marketplace, Takeout, Calendar, Chat/Meet, MDM, Alert Center recipients.
  4. Quarter — Level 3 + ops. DLP/CAA/Gemini (if licensed), Security Sandbox on Ent Plus, plus the operating checklist below. Start Phase-2 backlog.

Operating rhythm (process layer)

Config without owners is not Level 2. Tick these with the client even when every Admin toggle is green.

  • Offboarding runbook: suspend → wipe mobile → transfer Drive → remove groups → revoke OAuth → confirm Takeout off.
  • Break-glass: 2–4 super admins, spare security keys offline, recovery not on personal Gmail.
  • Alert Center: two humans (or a security group) on high-severity alerts — not only an unused super-admin mailbox (A7).
  • Security Health: review monthly for 90 days post go-live, then quarterly.
  • Admin audit log: sample privileged changes monthly; investigate unexpected role grants.
  • Compromised account play: suspend → password reset → revoke sessions/tokens → Email log search → re-enable with 2SV proof.
  • OAuth / Marketplace review: re-check connected apps 48h after API restriction and quarterly thereafter (C2/C4).
  • DMARC reports: watch rua for 2–4 weeks before moving p=quarantine → p=reject.

“Google’s new-tenant defaults (Level 0) are not a security baseline.
